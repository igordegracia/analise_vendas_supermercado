Análise de Estatística de Vendas - Supermercado

Projeto de análise de dados desenvolvido para uma loja de varejo, com o objetivo de extrair insights acionáveis a partir de dados históricos de vendas e fornecer **evidência estatística** para embasar decisões da equipe de marketing.

Objetivo

Analisar dados diários de vendas do último ano de operação da loja, combinando:

- **Estatística Descritiva** — para caracterizar e resumir o comportamento dos dados.
- **Estatística Inferencial** — para testar hipóteses e generalizar conclusões.

As análises respondem a 14 perguntas de negócio formuladas pela equipe de marketing, sempre com interpretação no contexto da loja — não apenas números soltos.
